FACE ID + BLOCKCHAIN VERIFICATION PIPELINE
==========================================
HH Goa 2026 - Task 3: Face Identification & Blockchain Verification

WHAT IT DOES
------------
End-to-end pipeline:
  face scan -> genuine reverse-image search -> blockchain record -> re-verify

  1. Face detection & encoding (OpenCV) -> SHA256 face hash
  2. GENUINE reverse image search: input image is uploaded to a temporary
     public host (catbox.moe / 0x0.st), then queried against Google via
     SerpApi (Google Lens). Returns a real matching web/social post.
     Not hardcoded - it is a live search.
  3. Blockchain record: the face hash + matched post URL + metadata are
     written to the FaceRegistry smart contract on the Ethereum Sepolia
     testnet as a tamper-evident record (real transaction).
  4. Re-verification: verify.py reads the record back from the chain and
     re-hashes any image to confirm a MATCH or detect TAMPERING.

HOW TO RUN
----------
  pip install -r requirements.txt
  cp .env.example .env        # add SERPAPI_KEY, ETHEREUM_RPC_URL, ETHEREUM_PRIVATE_KEY
  python contract/deploy.py    # deploy contract (fills CONTRACT_ADDRESS)

  python pipeline.py --image <face.jpg>            # full pipeline (+ QR certificate)
  python verify.py  --record-id 0x<id>             # read record back from chain
  python verify.py  --image <face.jpg>             # re-hash -> MATCH / TAMPER DETECTED

BLOCKCHAIN USED
---------------
  Ethereum Sepolia public testnet, via Infura RPC, Solidity contract
  (FaceRegistry.sol) deployed with web3.py + py-solc-x.

KNOWN LIMITATIONS
-----------------
  - Face detection is OpenCV edge/contour based, not true face recognition.
  - Reverse-search coverage depends on Google's index: widely-online faces
    return rich social matches; a brand-new private photo may return few/none.
  - Temp image hosts (catbox.moe / 0x0.st) are public - don't use sensitive images.
  - Sepolia is a testnet (not production); confirmation ~15-120s.
